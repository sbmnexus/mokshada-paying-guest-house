# Mokshda Paying Guest House

Static website for Mokshda Paying Guest House in Nagwa, Lanka, Varanasi.

**Live website:** https://mokshdapayingguesthouse.netlify.app/

## Website

The site provides information about the guest house, including:

- AC and Non-AC rooms and rates
- Room photos and facilities
- Address, nearby landmarks, and directions
- Phone, WhatsApp, and booking enquiries

## Project files

- `index.html` — website content, styles, and scripts
- `mokshda-paying-guest-house-logo.jpe` — brand logo
- `mokshada-entry.png`, `mokshada-room-1.png`, `mokshada-room-2.png` — gallery photos
- `mokshada-logo.png`, `favicon-192.png` — additional branding assets
- `robots.txt`, `sitemap.xml` — search-engine crawling and sitemap

## Preview locally

Open `index.html` in a web browser. The site is static and does not require a build step or package installation.

## Deployment

The live site is deployed with Netlify. Updates pushed to the connected `main` branch can trigger a new deployment.

## Search indexing

The site includes a canonical URL, page metadata, `robots.txt`, and `sitemap.xml`. To request Google indexing, verify the site in [Google Search Console](https://search.google.com/search-console/), submit the sitemap, and request indexing for the homepage.
