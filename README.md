# Mokshda Paying Guest House

This repository contains the static website for Mokshda Paying Guest House, a guest house and homestay in Nagwa, Lanka, Varanasi.

**Live website:** https://mokshdapayingguesthouse.netlify.app/

## Overview

The website helps visitors:

- view AC and non-AC room options and prices
- see room photos and property facilities
- find the location near BHU and Assi Ghat
- contact the owner directly by phone or WhatsApp
- check room availability before booking

## Project structure

- `index.html` — complete website markup, styles, and scripts
- `mokshda-paying-guest-house-logo.jpe` — property logo
- `mokshada-entry.png` — entrance/gallery image
- `mokshada-room-1.png` — room interior gallery image
- `mokshada-room-2.png` — additional room/gallery image
- `mokshada-room-3.png` — additional guest bedroom gallery image
- `mokshada-room-4.png` — additional guest bedroom gallery image
- `robots.txt` — crawler instructions for search engines
- `sitemap.xml` — sitemap for indexing
- `google2b1632fd4c37d58e.html` — Google verification file

## Local preview

Because this is a static site, there is no build step or dependency installation required.

You can preview it either by:

1. opening `index.html` directly in a browser, or
2. running a lightweight local server:

```bash
python -m http.server 8000
```

Then open: http://localhost:8000

## Deployment

The site is deployed on Netlify and is configured to publish from the connected `main` branch.
